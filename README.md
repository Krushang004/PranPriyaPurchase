# PranPriyaPurchase - Handmade Jewelry Website 💎

An immersive 3D website showcasing beautiful handmade paper bead necklaces and keychains crafted with love.

## ✨ Features

- **Immersive 3D Experience**: Interactive 3D galleries with floating beads and realistic jewelry models
- **Responsive Design**: Optimized for all devices with touch-friendly interactions
- **Vibrant Color Palette**: Inspired by the beautiful bead colors (#784563, #E75964, #FA863E, #E5B646, #63AAB8)
- **Performance Optimized**: WebGL fallbacks, FPS monitoring, and automatic quality adjustment
- **Accessible**: Support for reduced motion, high contrast, and keyboard navigation

## 🎨 Design Inspiration

The website captures the vibrant, handmade essence of PranPriyaPurchase jewelry:
- **Paper Bead Necklaces**: Golden sun pendants, turquoise & pink combinations, elegant blue patterns
- **Character Keychains**: Cute frog couples, adorable animals, and colorful bead tassels
- **Typography**: Elegant serif and sans-serif combination (Playfair Display + Inter)

## 🛠️ Technologies Used

- **HTML5**: Semantic structure and accessibility
- **CSS3**: Advanced animations, gradients, and responsive design
- **JavaScript**: ES6+ with modern features
- **Three.js**: 3D graphics and WebGL rendering
- **GSAP**: Smooth animations and scroll effects

## 🚀 Getting Started

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Krushang004/PranPriyaPurchase.git
   cd PranPriyaPurchase
   ```

2. **Serve the website**:
   ```bash
   # Using Python
   python -m http.server 8080
   
   # Using Node.js
   npx http-server
   
   # Using PHP
   php -S localhost:8080
   ```

3. **Open in browser**:
   Navigate to `http://localhost:8080`

## 🎯 Performance Features

- **FPS Monitoring**: Automatic quality adjustment based on device performance
- **Memory Management**: Proper cleanup of 3D resources
- **Intersection Observer**: Efficient canvas rendering when visible
- **Preloading**: Critical resources loaded in advance
- **Hardware Acceleration**: GPU-optimized animations
